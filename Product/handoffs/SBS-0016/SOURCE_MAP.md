## 规格核对提示（非新增范围）

1. 只读示意的标识应持续可见；示意值不得与实际 KOL 数量合算，也不能因打开示意模式改变真实资料或允许编辑样例。
2. 源会将被移出设置的负责人/模块继续从任务中汇总为筛选项。新的设置编辑不应导致已有任务不可发现。
3. JSON “完整备份”与“追加导入不覆盖设置”是两个不同语义；预览应说明追加任务/事件线/节点、当前设置和布局如何保留。2 MB / 300 条边界应有明确计数合同和失败原子性验证。
4. 无任务完成率 `—` 已由 SBS 明确定义；不能为凑齐图表把未知实际指标写成 0 或把示意当实况。
5. 本步完整能力映射不代表验收通过。工程结果、视觉和真实交互需使用 SBS-0016 的最终候选独立记录，不能复用 SBS-0015 的 PASS。
