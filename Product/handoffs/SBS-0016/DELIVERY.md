## 现在怎样使用

打开本机 [我的工作台](http://127.0.0.1:3108/dashboard)，使用现有演示身份登录。顶部业务导航与品牌不变，侧栏增加四个子页：

| 页面 | 用途 |
| --- | --- |
| 工作台总览 | 六项项目指标、状态环、优先级分布、成员负载、近期交付、里程碑和最近动态 |
| 任务看板 | 按状态或负责人分组，可拖动卡片；切换横向表格，按模块、负责人、优先级、文字筛选 |
| 项目时间轴 | 任务甘特与项目节点两种视图；30/45/60/90天，支持前后平移、今天、起始日 |
| 人员进度 | 按负责人汇总任务、阶段、平均手工进度与近期交付 |
| KOL协作概览 | 读取现有KOL达人、合作及有效排期，提供入库、合作进度、发布计划、日历入口 |

首次打开是完整零态，不自动灌入原型数据。点“查看只读示例”可看带任务的布局；退出后回到自己的资料，示例不会保存。

“项目设置”可改项目名称、成员、模块，选择首页区块及顺序。取消有明确草稿提示，只有保存才生效。删除名单中的成员/模块不会让已有任务在筛选中消失。

“新增任务”设置负责人、状态、优先级、起止日期、说明与手工进度；可加最多20个任务节点。待办固定0%，已完成100%；从已完成退回其他状态归0再维护。节点必须在任务周期内。点击任务名称编辑，删除需确认；拖动的状态/负责人操作都有表单替代。

在项目关键节点页可新建事件线，点击日期添加节点，点击节点修改日期/说明。当天多个节点分层显示，时间轴可横向滚动。默认线保留；删除其他线时，其节点归入默认线而不丢失。

提醒包含未完成任务逾期/未来7天、任务节点逾期/未来3天、项目节点前后3天。提醒只是本机计算，不发送通知。

“数据备份与导出”提供当前视图CSV及完整JSON。JSON追加导入先显示数量，再确认；重分配记录ID，不覆盖已有任务或项目设置。仅支持本模块备份，最大2MB/300条；重复导入会产生多份新记录。原HTML格式需专项映射，不能与KOL名册混为一库。
