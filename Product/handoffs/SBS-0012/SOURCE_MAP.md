# 三方号需求到本轮实现

2026-10-19。根目录DOCX完整61段/2表/7图；V5.0 HTML完整3511行。保留只读原件。执行与验收见[SBS-0012](../../../SBS/SBS-0012-third-party-publishing.md)。

| 来源要求/参考 | 本轮安排 | 边界 |
|---|---|---|
| 用户保留发布总览、全局透视、账号与作品 | 原历史7页保留，账号/作品各自卡片与横表切换 | 同一筛选/聚合/排序/分页，不复制统计 |
| DOCX两表账号/主页/类型/人设/结算/手机号/供应商/管理人员/状态 | 入库/编辑表单、资料表和详情 | UID生成B站主页；手机号选填；状态人工维护 |
| 蘑菇/伏羲标记 | 归属标签与筛选，供应商另列 | 历史财义不改成伏羲，不推断无来源标签 |
| 昵称进主页、最新3视频 | 资料表主页链接；详情/日历右栏3条真实历史作品 | 无历史显示暂无，未知指标用— |
| 发布计划关联日历 | 同源排期表+月历，独立账号/排期ID | 手动建立具体日期时间；一账号一天多档互不覆盖 |
| HTML42格/今天/月切换/筛选/右侧栏 | 沿用版式，新增/编辑/跨月改期/取消恢复/键盘 | 右侧不静默丢弃第24条以后的记录 |
| 原型多平台/语言 | DOCX限定B站only | 不扩多平台发布闭环 |
| 原型150账号与效果指标 | 不导入seed | 与原85账号/374作品快照不混用 |
| 内容审核/AI排日历 | 手动内容与待确认/人工确认 | 不代表AI、平台审核或实际发布 |
| 每日抓取/效果更新/KPI分类 | 保留既有历史发布/统计页 | 无采集接口，计划不会更新历史效果 |
| KPI结算/试错期/回收 | 留待研究 | 满足KPI收回与不达标回收冲突，阈值/起算点未定 |

HTML按账号+日期覆盖多个档期、自动补足不遵守上限、schema变化重seed、吞存储错误等实现不继承。新仓储明确身份、版本、失败与草稿，原件不改。

采用现有tokens、Radix/shadcn控件；Emil设计工程用于快反馈、模态焦点与低动效。未新增依赖，设计参考仓不导入运行时。
