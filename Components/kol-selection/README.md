2026-11-07 当前范围由 SBS-0021 / DEC-029 覆盖：KOL侧栏12项直接显示，不折叠；工作室9页（撤下资料与数据，保留策划排期），合作进度，以及发布效果首页/全局透视。旧发布计划/日历/入库独立页已撤；合作资料和已建计划在合作进度同页管理。upstream原件、数据库、顶栏导出备份保留；三方号不变。下文十模块/旧四管理页是历史接入说明。

## 十个工作区

| 视图 ID | 页面 | 保留能力 |
|---|---|---|
| `kols` | UP资料库 | 检索筛选、头像、粉丝/报价、作品表现、来源与详细档案、选人及编辑 |
| `pool` | 中选池 | 中选 UP/创意、组合阵容、移入移出、直接排期 |
| `ideas` | 创意提词板 | 创意详情与图片、成员分摊报价、手填总价、预算纳入、归档/恢复 |
| `factory` | 脑暴工厂 | 底板与标准件、拖放组合、自定义模板、报价计算、生成或更新提词卡 |
| `calendar` | 策划排期 | 月/周视图、拖动排期、节点、具体日期/某周/日期待定、右侧详情与预算 |
| `overview` | 策划总览 | 人选、创意、预算和覆盖的工作概览 |
| `relations` | 合作关系图 | 共同作品证据、创意组合建议、图谱筛选与详情、人工合作记录 |
| `budgets` | 预算与覆盖 | 预算分类、额度、创意费用与覆盖；不等同采购审批或实际付款 |
| `selling` | 卖点地图 | 卖点与人选、创意的关联及覆盖 |
| `sources` | 资料与数据 | 来源说明、导入/导出、管理员历史版本；按权限提供 |

## 数据及运行边界

完整保全与源目标映射见 [SOURCE_MAP](../../Product/handoffs/SBS-0019/SOURCE_MAP.md)。保全基线为963个 UP、25位中选 UP、96项创意（82活跃、14归档）、10预算分类、13卖点和13排期节点。`dist/data.json`只有95项创意，是旧seed；真实网关不会用它覆盖工作数据库。

阿里云目标是复用原 `/var/lib/kol-workbench/workspace.sqlite`，与原 `/kol/` 共用同一版本和保存历史；本机保全与运行测试副本均在 `.local/sbs-0019/`。原始业务文件与工作数据库不在 Next public，不提供匿名下载。所有 `/kol-studio/` 资源及 API 由新网关鉴权；新 Mikoshi 账号不自动获得旧脑图账号。

新增身份分管理员、编辑、只读。管理员管理邀请并读取历史版本；管理员和编辑可写 KOL 工作资料；只读成员不可写。授权读写仍由服务端检查，隐藏按钮不构成权限边界。原保存版本冲突返回409，不能使用无条件覆盖“解决”冲突。

原 KOL 发布效果七页和发布/合作管理四页继续存在，数据模型没有合并。三方号、旧 KOL 管理、营销工作台等既有本机模块仍按各自浏览器数据合同运行；部署整个页面外壳不代表这些模块已实现团队云同步。

本目录源码接入已经完成，云端实际上线及统一验收状态以 [交付说明](../../Product/handoffs/SBS-0019/DELIVERY.md)和 SBS 正文为准。
